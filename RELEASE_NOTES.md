# Release Notes

## 15.1.0 — 2026-11-16

### Added

- Combine the Core CLI and web application in one repository.
- Add `core-cli` and `core-web` executable entry points.
- Add npm package metadata and the npm publication workflow.

### Changed

- Set the package name to `@eliware/core` and use the Core Networking Manager identity.
- Set the default web port to `9300`.
- Keep the web app build, API example, offline support, and browser checks.
- Keep CLI help, version, argument checks, and focused tests.
